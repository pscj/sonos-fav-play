# Sonos 自动播放脚本

一个用于自动播放 Sonos 收藏夹内容的 Python 脚本,支持自动发现设备和提取播放参数。

## ✨ 特性

- 🤖 **自动发现设备** - 无需手动配置 IP 地址
- 🎯 **一键切换频道** - 只需修改收藏夹名称即可
- 🔧 **自动提取参数** - 自动从收藏夹元数据提取所有必需参数
- 👑 **智能选择组长** - 自动选择组长设备进行播放

## 📋 依赖要求

- Python 3.x
- SoCo 库 (Sonos 控制库)

## 🚀 安装

1. 克隆或下载此项目

2. 安装依赖:
```bash
pip3 install -r requirements.txt
```

## 📖 使用方法

### 基本使用

1. 确保你的 Sonos 设备和运行脚本的电脑在同一网络
2. 将想要播放的内容添加到 Sonos 收藏夹
3. 修改脚本中的 `target_fav_name` 参数:

```python
target_fav_name = "摸鱼早报"  # 改成你的收藏夹名称
```

4. 运行脚本:
```bash
python3 playsonos.py
```

### 切换频道

只需修改 `target_fav_name` 参数为新的收藏夹名称,然后重新运行脚本即可。

## 🔍 工作原理

脚本会自动执行以下步骤:

1. **发现设备** - 扫描网络中的 Sonos 设备
2. **选择组长** - 优先选择组长设备(或自动切换到组长)
3. **提取参数** - 从收藏夹元数据中提取:
   - UUID (播放列表标识符)
   - SERVICE_ID (服务 ID)
   - ACCOUNT_ID (账户凭证)
4. **构造播放 URI** - 使用提取的参数构造播放链接
5. **开始播放** - 清空队列并开始播放

## ⚙️ 配置参数

### target_fav_name
- **类型**: 字符串
- **说明**: Sonos 收藏夹中的内容名称
- **示例**: `"摸鱼早报"`, `"BBC News"`

### MAGIC_HEX_PREFIX
- **类型**: 字符串
- **默认值**: `"2064"`
- **说明**: URI 构造时的魔法前缀,通常不需要修改
- **注意**: 如果遇到 800 错误,可以尝试改为 `"6028"`

## 🐛 故障排除

### 未发现任何 Sonos 设备
- 检查设备是否在同一网络
- 检查防火墙设置
- 确保 Sonos 设备已开机

### 无法提取必需参数
- 检查收藏夹名称是否正确
- 确保收藏夹中的内容已正确添加
- 查看控制台输出的详细错误信息

### 播放失败 (800 错误)
- 尝试修改 `MAGIC_HEX_PREFIX` 为 `"6028"`
- 检查账户凭证是否有效
